# Piano: Mostrare numero di telefono accanto al nome del contatto

## Obiettivo

In tutte le pagine dove viene mostrato il nome di un contatto, mostrare anche il numero di telefono con scrolling orizzontalmente se necessario.

## Approccio

### 1. Estrarre il numero dal JID

Il JID è nel formato `numero@s.whatsapp.net`. Il numero può essere estratto con:

```kotlin
val phoneNumber = jid.substringBefore("@").takeIf { it.contains(Regex("\\d")) }
```

### 2. Componente UI condiviso

Creare un componente `ContactNameWithPhone` riutilizzabile che:

- Mostra il nome
- Se disponibile il numero, aggiunge " - " + numero (trattino con spazi)
- Usa `SingleLine` con scrolling orizzontale (`overflow = TextOverflow.Ellipsis`)
- Font del numero più piccolo (`bodySmall` vs `titleMedium`)

### 3. Modifiche ai model (opzionale - verificare se necessario)

I model come `CallStat`, `LinkStat` hanno già il campo `jid` dal quale estrarre il numero. Non servono modifiche ai model.

## File da modificare

### Nuovo componente

Creare `ContactNameWithPhone.kt` in `ui/component/`:

```kotlin
@Composable
fun ContactNameWithPhone(
    name: String,
    jid: String?, // per estrarre il numero
    modifier: Modifier = Modifier,
    nameStyle: TextStyle = MaterialTheme.typography.titleMedium,
    showPhone: Boolean = true
) {
    val phone = jid?.substringBefore("@")?.takeIf { Regex("\\d").containsMatchIn(it) }

    Row(
        modifier = modifier,
        verticalAlignment = Alignment.CenterVertically
    ) {
        Text(
            name,
            style = nameStyle,
            maxLines = 1,
            overflow = TextOverflow.Ellipsis,
            modifier = Modifier.weight(1f, fill = false)
        )
        if (showPhone && phone != null) {
            Text(
                " - $phone",
                style = MaterialTheme.typography.bodySmall,
                color = MaterialTheme.colorScheme.onSurfaceVariant,
                maxLines = 1,
                overflow = TextOverflow.Ellipsis
            )
        }
    }
}
```

# Fix: ContactNameWithPhone - nome sempre visibile, telefono scrollable

## Problema attuale

Il nome va in overflow con ellipsis, mentre il numero dovrebbe essere quello scrollable. L'utente vuole:

- **Nome**: SEMPRE visibile (mai ellipsis), su "sua linea"
- **Telefono**: scorrevole/ellipsis se troppo lungo

## Fix da implementare

Nel componente `ContactNameWithPhone.kt`:

**Prima (attuale)**:

```kotlin
Row(...) {
    Text(name, overflow = Ellipsis, modifier = Modifier.weight(1f))
    Text("  ·  $phone", overflow = Ellipsis)
}
```

**Dopo (corretto)**:

```kotlin
Column(modifier.fillMaxWidth()) {
    // Riga 1: Nome - sempre visibile, no overflow
    Text(
        name,
        style = nameStyle,
        maxLines = 1,
        overflow = TextOverflow.None,  // key: mostra tutto il nome
        modifier = Modifier.fillMaxWidth()
    )
    // Riga 2: Telefono - scrollable
    if (showPhone) {
        Row(
            modifier = Modifier.fillMaxWidth()
                .horizontalScroll(rememberScrollState()),
            verticalAlignment = Alignment.CenterVertically
        ) {
            Text("- $phone", style = phoneStyle)
        }
    }
}
```

Note:

- Usare `horizontalScroll` per il telefono (import `Row` con scroll)
- Oppure usare `TextOverflow.Ellipsis` senza scroll per semplicità
- Il nome avrà sempre il trattino ma su riga separata

Oppure in Row unico:

```kotlin
Column {
    Text(name, overflow = TextOverflow.None)  // sempre visibile
    Text("- $phone", overflow = Ellipsis)  // scrollable
}
```

# Fix: Media/giorno deve usare l'intervallo temporale selezionato

## Problema
La statistica "Media/giorno" attualmente calcola:
```
totale_messaggi / giorni_dal_primo_messaggio
```

Dovrebbe invece usare l'intervallo temporale selezionato (Today, Last 7 days, Custom, ecc.):
```
totale_messaggi / giorni_nell_intervallo_selezionato
```

## Implementazione

Modificare `AnalyticsRepository.kt` nella funzione `getQuickGlobalStats` (circa linea 95-101).

### Prima (attuale):
```kotlin
val avgPerDay = if (oldestTs > 0) {
    val daysSinceFirst = ((System.currentTimeMillis() - oldestTs) / 86400000f)
        .coerceAtLeast(1f)
    totalMessages / daysSinceFirst
} else {
    0f
}
```

### Dopo (corretto):
```kotlin
val avgPerDay = if (startTime != null && endTime != null) {
    // Usa l'intervallo temporale selezionato
    val daysInRange = ((endTime - startTime) / 86400000f).coerceAtLeast(1f)
    totalMessages / daysInRange
} else if (oldestTs > 0) {
    // Fallback per ALL_TIME (usa data primo messaggio)
    val daysSinceFirst = ((System.currentTimeMillis() - oldestTs) / 86400000f)
        .coerceAtLeast(1f)
    totalMessages / daysSinceFirst
} else {
    0f
}
```

## Note
- `startTime` e `endTime` sono già calcolati nella funzione (linea 53-57)
- Il calcolo è già corretto per CUSTOM range
- Per ALL_TIME (`startTime = null`) si usa il fallback con la data del primo messaggio
- Non serve modificare il ViewModel o la UI

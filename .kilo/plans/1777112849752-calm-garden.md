# Piano: Schermate Tutorial per WhatStat Reborn

## Decisioni Utente
- **Layout**: PageView scorrevole (swipe/pager)
- **Avvio**: Automatico al primo avvio + accessibile da 6° tab bottom navigation
- **Screenshot**: Placeholder con icona (box grigio con icona, da sostituire poi)
- **Pulsante "Salta"**: Sì, su ogni pagina per chiudere subito il tutorial

---

## Struttura Tutorial (7 step)

### Step 1: Benvenuto / Setup
- Spiega che l'app funziona solo su dispositivo rootato
- Cosa serve: Magisk, WhatsApp con backup E2E disattivato
- Cosa fa: estrae, decifra e analizza il database in locale

### Step 2: Dashboard (Panoramica Globale)
- Statistiche riepilogo: messaggi totali, chat, contatti, media
- Media messaggi/giorno, chat più attiva, ora/giorno più attivo, streak
- Grafici attività: oraria, settimanale, mensile, annuale
- Analisi testi: parole più usate, emoji, sticker (opt-in)

### Step 3: Lista Chat
- Ranking conversazioni per numero messaggi
- Avatar, nome contatto, numero, conteggio messaggi
- Navigazione al dettaglio

### Step 4: Dettaglio Chat
- Statistiche base: messaggi inviati/ricevuti, lunghezza media
- Chi scrive di più (donut chart per gruppo)
- Chi inizia le conversazioni (dopo 3 ore di silenzio)
- Grafici attività, evoluzione mensile
- Analisi testi per chat e per persona
- Log chiamate, Media & Link
- Cronologia gruppi (timeline eventi)

### Step 5: Media Gallery
- Griglia foto/video condivisi nelle chat
- Zoom, ordinamento, lazy loading

### Step 6: Radar Parole
- Ricerca parole/frasi in una chat
- Breakdown per mittente

### Step 7: Privacy
- Nessuna connessione di rete
- Tutto in locale, file privati

### Struttura Navigazione
```
NavHost
  └── SetupGraph
  │    └── SetupScreen
  └── MainGraph
       ├── TutorialScreen (accessibile da 6° tab, parte al primo avvio)
       ├── BottomNavigationBar (6 tabs: Panoramica, Chat, Media, Radar, Chiamate, Tutorial)
       └── ...altre schermate
```

### Bottom Navigation a 6 tab
- Aggiungere un 6° tab "Tutorial" con icona `Icons.Default.HelpOutline`
- Il tab apre direttamente la schermata Tutorial

### Avvio automatico al primo avvio
- In `SetupScreen`, dopo `onSetupComplete`, verificare se `has_seen_tutorial` è false
- Se sì, navigare al Tutorial invece che direttamente al Main
- Dopo che l'utente chiude il tutorial (tap "Salta" o swipe all'ultima pagina), salvare `has_seen_tutorial = true`
- Nei avvii successivi, il tab Tutorial è disponibile ma non parte automaticamente

### Navigazione Tutorial
- Swipe orizzontale per navigare (HorizontalPager)
- Pulsante "Salta" in alto a destra su ogni pagina (eccetto ultima) → chiude il tutorial e imposta `has_seen_tutorial = true`
- Sull'ultima pagina, il pulsante "Salta" diventa "Fine"
- Al tap "Fine" → naviga alla schermata principale (Dashboard) e imposta `has_seen_tutorial = true`

### Dettagli UI Placeholder Screenshot
- Box con `aspectRatio = 16f/9f`
- `border = BorderStroke(1.dp, Color.Gray.copy(alpha = 0.5f))`
- `background = Color.Gray.copy(alpha = 0.1f)`
- Icona `Icons.Default.Image` centrata (colore grigio)
- Testo piccolo sotto icona: "Screenshot" opzionale

### Dettagli UI Page Indicator
- Row di cerchietti in basso
- Cerchietto attivo: filled con primary color
- Cerchietto inattivo: outlined o grigio

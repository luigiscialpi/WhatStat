## Implementazione

### 1. Fix Word Search

**Comportamento desiderato**:
- **Dashboard (globale)**: Cerca in quale chat appare la parola + count totale per chat. Se è un gruppo, nel tooltip mostra breakdown per partecipante.
- **Chat Detail**: Mostra count totale nella chat + breakdown per sender (chi l'ha scritta e quante volte).

**Query necessaria**:
- Già implementata per globale: `searchWordFrequency(word, chatId, startTime, endTime)` → raggruppa per chat
- Nuovo metodo per detail: `searchWordFrequencyBySender(word, chatId, startTime, endTime)` → raggruppa per sender

**Problema attuale**: La query non restituisce risultati. Potrebbe essere problema di NULL in text_data o parametri.

### 2. Tooltip Dettaglio Gruppi (Dashboard Media & Links)

**Comportamento**: Quando preme su una chat nel grafico:
- **Se gruppo**: Lista partecipanti con count link ciascuno (usa nomi da jid owa_contacts)
- **Se chat singola**: Mostra 3 cose:
  - Totale link
  - Quante volte "Me" ho condiviso
  - Quante volte [Nome Contatto] ha condiviso (usa nome reale se disponibile, altrimenti "Altro")
- La somma di Me + Altro deve uguagliare il Totale

**Query necessaria**:
- Nuovo metodo in MessageDao: `getLinkStatsBySender(chatId, startTime, endTime)`
- Per gruppi: join con `group_participants` per ottenere nomi
- Per chat singole: conta where from_me=1 (Me) vs from_me=0 (Altro)

### 3. Media & Links in Chat Detail

**Comportamento**:
- **Chat singola**: 3 righe (Totale + "Me" + [Nome Contatto])
- **Gruppo**: Lista partecipanti + Totale
- Totale = somma di tutti
- Usa nomi reali da jid.user o wa_contacts, fallback a "Me" e "Altro"

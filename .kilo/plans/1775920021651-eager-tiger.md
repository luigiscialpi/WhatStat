# Piano di Implementazione - WhatStat

## Scenario
L'utente ha un database crypt14 che non riesce a essere decifrato internamente dall'app. Ha già uno strumento esterno (wadecrypt.exe su Windows) che funziona.

## Obiettivi

### Fase 1: Supporto per DB già decifrato (IMMEDIATO)
- Permettere all'utente di importare un file `msgstore.db` già decifrato
- L'app lo apre direttamente come SQLite senza bisogno di decifrazione

### Fase 2: Integrazione wa-crypt-tools (SUCCESSIVO)
- Bundlare wa-crypt-tools dentro l'app Android
- Eseguire la decifratura automaticamente all'interno dell'app

---

## Piano - Fase 1: Import DB già decifrato

### Modifiche necessarie:

1. **SetupScreen.kt** - Aggiungere opzione per selezionare database già decifrato
   - Nuovo pulsante "Database già decifrato (msgstore.db)"
   - Tipo file: `*/*` o `.db`

2. **SetupViewModel.kt** - Gestire il nuovo tipo di file
   - Nuovo stato: `hasManualDbDecrypted`
   - Nuovo `fileDestName`: es. `WA_DB_DECRYPTED_DEST`

3. **SetupService.kt** o **WhatsAppRepository.kt** - Saltare la decifratura
   - Se l'utente fornisce `msgstore.db` già decifrato, passare direttamente al database opening
   - Verificare che sia un SQLite valido ("SQLite format 3")

4. **FileExtractor.kt** - Aggiornare i path supportati
   - Aggiungere `WA_DB_DECRYPTED_DEST = "msgstore.db"` (file già decifrato)

---

## Piano - Fase 2: Integrazione wa-crypt-tools

### Opzioni:
1. **Bundlare wa-decrypt.exe** (binario precompilato) - Più semplice
2. **Bundlare Python + wa-crypt-tools** - Più complesso, APK più grande
3. **Eseguirewa-decrypt come sottoprocesso** - Richiedewa-decrypt nell'APK

### Modo più pratico:
- Bundle `wadecrypt.exe` nella cartella `assets` dell'APK
- In fase di setup, copiare l'eseguibile nella directory interna dell'app
- Eseguire come processo: `wadecrypt key msgstore.db.crypt14 msgstore.db`
- Leggere l'output e verificare successo

### Fallback:
- Se wa-crypt-tools fallisce, mostrare messaggio con istruzioni per decifrare esternamente

---

## Priorità di implementazione

1. FASE 1 (immediata): Import db già decifrato - 1-2 ore
2. FASE 2 (dopo): Integrazione wa-crypt-tools - 3-4 ore

L'utente preferisce procedere subito con FASE 1, poi FASE 2.

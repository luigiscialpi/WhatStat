# Piano: Image Viewer con Pinch-to-Zoom e Rotazione

## Obiettivo
Migliorare l'anteprima immagine nella Media Gallery aggiungendo:
- Pinch-to-zoom con panning
- Rotazione a due dita
- Double tap per toggle zoom (fit ↔ 2x)
- Swipe down per chiudere
- Pulsante X in alto a destra
- Tasto back Android

## Dipendenze Necessarie

**Non servono librerie aggiuntive.** Compose fornisce nativamente:
- `Modifier.transformable()` per pinch-to-zoom + pan
- `graphicsLayer` per scale e rotation
- Gesture APIs per double tap e drag-to-dismiss

## Implementazione

### 1. Componente `ZoomableImageViewer` (nuovo)

Creare un composable riutilizzabile con:

```kotlin
@Composable
fun ZoomableImageViewer(
    filePath: String,
    onDismiss: () -> Unit,
    modifier: Modifier = Modifier
)
```

**Feature implementate:**

| Feature | Implementazione |
|---------|------------------|
| Pinch-to-zoom | `Modifier.transformable()` con `TransformableState` |
| Pan quando zoomato | Incluso in `transformable` |
| Rotazione 2 dita | `graphicsLayer { rotationZ = angle }` aggiornato da `PointerInputScope.detectTransformGestures` |
| Double tap zoom | Toggle 1x ↔ 2.5x via `detectTapGestures(onDoubleTap = {...})` |
| Swipe down close | `detectVerticalDragGestures` con threshold 150dp, chiude se overscroll superato |
| Click esterno close | Touch fuori dall'immagine chiude |
| Back button Android | `BackHandler { onDismiss() }` |
| Pulsante X | `Icons.Outlined.Close` in alto a destra con `IconButton` |

### 2. Comportamento Zoom

- **Zoom minimo:** 1.0x
- **Zoom massimo:** 5.0x
- **Double tap:** toggle tra 1.0x e 2.5x
- **Reset al dismiss:** lo stato di zoom si resetta quando viene chiuso

### 3. Comportamento Rotazione con Snap

**Durante rotazione (2 dita):**
- Rotazione libera continua (qualsiasi angolo da 0° a 360°)

**Al rilascio (2 dita):**
- Animazione di "snap" verso il multiplo di 90° più vicino
- Formula: `nearestMultipleOf90 = ((angle + 45) / 90).toInt() * 90`
- Esempi: 0°-44.9° → 0°, 45°-134.9° → 90°, 135°-224.9° → 180°, 225°-314.9° → 270°, 315°-359.9° → 0° (360°)
- Animazione: 250ms con `easeOut` curve
- Durante l'animazione di snap, lo zoom viene temporaneamente disabilitato per evitare conflitti

**Al dismiss:**
- Stato resettato (zoom e rotazione tornano a defaults)

### 4. Swipe-to-Dismiss

- Threshold: 150dp di drag verso il basso
- Opacità sfondo diminuisce durante drag (da 0.9f a 0.5f)
- Se threshold superato → chiudi
- Se no → anima ritorno alla posizione originale
